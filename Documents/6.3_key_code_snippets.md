## Snippet 1 — Temporal PageRank & Algorithmic Bootstrapping (graph_adapter.py)
```python
def get_character_importance(self, name, current_chapter=0, decay_rate=0.05):
    # 1. Weighted PageRank (Narrative intensity mapped to edge weights)
    pagerank_scores = nx.pagerank(self.graph, alpha=0.85, weight="weight")
    score = float(pagerank_scores.get(name, 0.0))
    
    # 2. Temporal Decay (Exponential degradation for absent characters)
    if current_chapter > 0 and max_chapter > 0:
        age = max(0, current_chapter - max_chapter)
        score *= (1.0 - decay_rate) ** age

    # 3. DPQ Bootstrapping (Provisional graduation for local dominance)
    if first_seen == current_chapter:
        dpq = self.get_debut_prominence(name, debut_chapter_id=current_chapter)
        if dpq >= 0.40: return max(score, DELTA_UPPER + 0.01)
    return score
```
This algorithm uniquely combines global graph topology (PageRank) with narrative time (decay). The **Debut Prominence Quotient (DPQ)** solves the "Silent Protagonist" problem, ensuring main characters introduced before the graph is dense enough receive their resources (like voices) immediately.

## Snippet 4 — Resource Graduation Logic (graduation.py)

```python
def check_graduation_status(character: CharacterRuntime, wiki_traits=None) -> bool:
    new_level = evaluate_graduation(character.confidence_score)
    
    if new_level == GraduationLevel.MAIN_CAST and character.voice_id is None:
        # Voice Locking: Assign permanent TTS voice from pool
        character.voice_id = assign_voice(character.character_id, merged_traits)
        return True
    elif new_level != GraduationLevel.MAIN_CAST and character.voice_id is not None:
        # Release voice lock if character decays below threshold

        character.voice_id = None
        return True
    return False
```
The graduation system dynamically allocates expensive cloud resources only to entities whose centrality score passes the `MAIN_CAST` threshold, ensuring efficient scaling for stories with thousands of background characters.

## Snippet 7 — Resilience Telemetry Decorator (retries.py)
```python
def with_retry(max_retries=3, stage="unknown"):
    def decorator(func):
        def wrapper(*args, **kwargs):
            try: return func(*args, **kwargs)
            except ExternalServiceError as e:
                if attempts >= max_retries:
                    # Emit structured telemetry for post-hoc analysis
                    with open("telemetry.jsonl", "a") as f:
                        f.write(json.dumps({"stage": stage, "error": str(e)}))
                    raise
                time.sleep(2 ** attempts)
```
Decouples retry logic from business logic. The telemetry emission allows for identifying which pipeline stages (e.g., "scrapper" vs "tts") are bottlenecks for engineering focus.
